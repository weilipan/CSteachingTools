🔁 Python 重複結構 for / while

告別複製貼上，從 DRY 原則出發，掌握迴圈的每一個細節

01 DRY 原則與迴圈的誕生

DRY 代表 Don't Repeat Yourself (不要重複你自己)。當你需要重複執行相同的動作時，交給迴圈就對了。

😩 人工苦力版 (複製貼上)
print("Hello")
print("Hello")
print("Hello")
print("Hello")
print("Hello")
✨ 自動化版 (使用 for 迴圈)
for i in range(5):
print("Hello")
// 點擊上方按鈕執行程式…

03 for 迴圈直接走訪集合 (Lists / Strings)

Python 的 for 迴圈不僅能搭配 range()，最強大的地方在於它可以直接將清單 (List) 裡的元素一個個拿出來執行！

fruits = ["🍎", "🍌", "🍇"]
for f in fruits:
print("吃掉：", f)

04 while 迴圈與無窮地獄

while 迴圈會在「條件為真 (True)」時不斷執行。如果你忘記在迴圈內更新條件變數，就會陷入當機的無窮迴圈！

hp = 50
while hp > 0:
print("攻擊！")
hp = hp - 10
print("安全結束")

06 時鐘齒輪：巢狀迴圈 (Nested Loops)

迴圈裡面還可以包迴圈！外層迴圈每轉動 1 次，內層迴圈就會完整執行一輪。

for i in range(3):
for j in range(4):
print(i, j)
⚙️ 大齒輪 = 外層 i（共轉 3 步）
⚙️ 小齒輪 = 內層 j（每次大齒輪動1步，小齒輪轉 4 步）

🏆 綜合實戰：「終極密碼」猜數字遊戲機

使用 while True: 建立遊戲主迴圈，並運用 break 在玩家猜對時跳出遊戲。

import random
target = 42
while True:
guess = int(input("猜："))
if guess > target:
print("太大了！")
elif guess < target:
print("太小了！")
else:
print("答對了！")
break
