5獨立 vs 互斥 — if/if vs if/elif 的陷阱

設定消費金額為：$250。觀察兩種寫法在領取滿額折價券時的不同結果。

❌ 兩個獨立 if（錯誤）

if amount >= 100: send_coupon(1) if amount >= 200: send_coupon(2)

✅ if + elif（正確）

if amount >= 200: send_coupon(2) elif amount >= 100: send_coupon(1)

8進階技巧 — 三元運算子 (Ternary Operator)

當 if/else 裡只有簡單的賦值操作時，Python 提供了一行寫完的優雅語法：
變數 = [條件成立的值] if [條件] else [條件不成立的值]

16

傳統寫法 (4 行)

if age >= 18: status = "成年" else: status = "未成年"

三元運算子 (1 行)

status = "成年" if age >= 18 else "未成年"
▶ status = "未成年"
