模組 3⚠️ 陷阱警告！輸入與型態轉換

input() 取得的資料永遠是字串 (String)。若要進行數學運算，必須經過型態轉換如 int() 或 float()。

❌ 錯誤示範（字串相加）

# 先轉換為 int 再運算 int(a) + int(b)

模組 7多重輸入必備：split() 切割術

當使用者一次輸入多個數值（例如 10 20），我們可以使用 .split() 根據指定符號將字串切割成列表 (List)。

data = "Apple,Banana,Orange" fruits = data.split(",") # 以逗號作為切割依據 print(fruits)
選擇切割符號：
"Apple,Banana,Orange"
