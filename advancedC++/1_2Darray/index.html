從基礎語法邁向演算法實戰，掌握二維陣列、方向陣列與模組化思維，為你的 APCS 檢定打下堅實基礎。

🛡️ APCS 考場生存指南

在 APCS 考場上，穩定度與執行效率是拿分的關鍵。以下是競程選手必備的「起手式模板」，請務必熟記！

1. 萬用標頭檔 #include <bits/stdc++.h>

這行魔法指令會一次載入 C++ 標準函式庫中所有的標頭檔（如 iostream, vector, algorithm 等）。在分秒必爭的考場上，這能為你省下大量回想與打字的時間。

2. 擊敗 TLE (Time Limit Exceeded)

C++ 為了相容 C 語言，預設會同步 cin/cout 與 scanf/printf 的緩衝區。加上 ios::sync_with_stdio(0); cin.tie(0); 可以解除同步，大幅提升 I/O 速度。
⚠️ 警告：加入這兩行後，絕對不可與 scanf/printf 混用，否則會導致輸出順序錯亂！

3. 全域變數黑魔法

APCS 題目常需要宣告大型二維陣列 (例如 int arr[1005][1005];)。如果宣告在 main() 裡面，會佔用 Stack 空間導致 Stack Overflow (RE)。宣告在 main() 之外（全域變數）會配置在 Data/BSS section，不僅空間大，還會自動初始化為 0。

APCS_Template.cpp
#include <bits/stdc++.h> using namespace std; // 【黑魔法】大陣列一律宣告為全域變數，避免 RE，且自動歸零 int R, C; int arr[1005][1005]; int main() { // 【防禦 TLE】優化 I/O 速度 (切記不可混用 scanf/printf) ios::sync_with_stdio(0); cin.tie(0); // 【對付 ZeroJudge】EOF 多筆測資讀取寫法 while (cin >> R >> C) { // 在這裡撰寫你的邏輯... } return 0; }

🧭 互動模擬：8 方向探索與邊界護城河

在二維網格問題中，「找鄰居」是最常見的操作。點擊下方網格，觀察方向陣列如何運作，以及程式碼如何判斷並阻擋「越界 (Out of Bounds)」造成的 RE。


請點擊上方網格的任意格子開始模擬
// 方向陣列 (上,下,左,右,左上,右上,左下,右下)
int dr[8] = {-1, 1, 0, 0, -1, -1, 1, 1};
int dc[8] = {0, 0, -1, 1, -1, 1, -1, 1};

for (int i = 0; i < 8; i++) {
int nr = r + dr[i];
int nc = c + dc[i];

// 🛡️ 護城河：邊界檢查
if (nr >= 0 && nr < 6 && nc >= 0 && nc < 6) {
// 安全！可以處理 arr[nr][nc]
process(nr, nc);
}
}

SDGs 7 太陽能板陣列最佳化
▼

📝 情境描述：可負擔的潔淨能源

為了最大化太陽能板的發電效率，工程師需要根據日照角度調整太陽能板陣列的方向。給定一個 N x M 的發電量矩陣，請將其進行「矩陣轉置 (Transpose)」，模擬陣列旋轉 90 度後的狀態，並找出發電量最高的新座標。

💡 教學亮點

學習二維陣列的轉置操作 (行列互換)。理解 arr[i][j] 轉置後變成 transposed[j][i] 的映射關係，並練習動態宣告不同維度大小的新陣列。

SDGs 14 珊瑚礁聲納地圖校正
▼

📝 情境描述：保育海洋生態

無人潛水艇回傳的珊瑚礁健康度聲納圖形，因為探測器裝反，導致地圖上下顛倒且左右相反。請撰寫程式將 N x N 的二維地圖進行「水平翻轉」再「垂直翻轉」，還原真實的珊瑚礁分佈圖。

💡 教學亮點

練習陣列的翻轉與旋轉。強調「暫存陣列 (Temp Array)」的重要性，展示如果直接在原陣列修改會導致資料被覆蓋的常見錯誤，培養安全的記憶體操作觀念。

SDGs 15 野火危險等級評估
▼

📝 情境描述：保育陸域生態

森林被劃分為 N x M 的網格，每個格子標示了植被乾燥度 (0~9)。若某格子的周圍 8 個方向中有超過 3 個格子的乾燥度大於 7，該格子就會被標記為「極高危險區」。請計算出地圖上有多少個極高危險區。

💡 教學亮點

完美結合方向陣列 (dr, dc) 與邊界防禦機制的實戰題。學生需要實作一個雙層迴圈掃描全圖，並在內部使用第三層迴圈檢查 8 個鄰居，是訓練多層迴圈邏輯的絕佳練習。

SDGs 2 尋找最佳科技農業區塊
▼

📝 情境描述：消除飢餓 (智慧農業)

政府提供了一張農地肥沃度地圖。為建立一座 2x2 的全自動無人溫室，你需要找出地圖中哪一個 2x2 區塊的肥沃度總和最高，並輸出該總和值與區塊左上角的座標。

💡 教學亮點

學習滑動視窗 (Sliding Window) 的基礎概念。特別強調迴圈邊界條件的設定 (`i < R-1` 且 `j < C-1`)，防禦存取 2x2 區塊右下角時發生越界溢位。

SDGs 3 變種病毒與免疫衰退模擬 (SIRS)
▼

📝 情境描述：健康與福祉

模擬病毒在城市中的傳播。每個格子有 4 種狀態：0(易感)、1(感染期第一天)、2(感染期第二天)、3(免疫期)。每天狀態轉移規則如下：
- 狀態 1 變 2，狀態 2 變 3，狀態 3 變 0 (免疫衰退)。
- 狀態 0 的人，若周圍 4 個方向有狀態 1 或 2 的人，則隔天變為狀態 1。請輸出 K 天後的地圖狀態。

💡 教學亮點 (壓軸題)

進階的狀態機轉移 (State Machine)。強烈警告學生「時間同步更新」的概念：絕對必須讀取原陣列 arr，並將下一天的結果寫入新陣列 temp_arr，最後再複製回去。如果不這麼做，新感染的人會在同一天的迴圈中立刻感染下一個人，導致一天內全城覆滅的邏輯錯誤。
