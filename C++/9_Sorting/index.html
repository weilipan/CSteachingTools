🫧 1. 氣泡排序 (Bubble Sort)

比較相鄰兩個元素，若左大於右則交換。每輪會把最大值「浮」到最右側。時間複雜度 O(N²)。

for (int i = 0; i < n - 1; i++) {   for (int j = 0; j < n - i - 1; j++) {     if (arr[j] > arr[j+1]) {       swap(arr[j], arr[j+1]);     }   } }

🔍 2. 選擇排序 (Selection Sort)

在未排序區間尋找「最小值」，並將其與未排序區的第一個元素交換。時間複雜度 O(N²)。

for (int i = 0; i < n - 1; i++) {   int minIdx = i;   for (int j = i + 1; j < n; j++) {     if (arr[j] < arr[minIdx]) minIdx = j;   }   swap(arr[i], arr[minIdx]); }

📌 3. 插入排序 (Insertion Sort)

將未排序的元素「抽出」，並在已排序的左側區段中由右至左尋找合適的插入位置。時間複雜度 O(N²)。

for (int i = 1; i < n; i++) {   int key = arr[i];   int j = i - 1;   while (j >= 0 && arr[j] > key) {     arr[j + 1] = arr[j];     j--;   }   arr[j + 1] = key; }

⚡ 4. 快速排序 (Quick Sort)

選擇一個 Pivot，將比它小的放左邊，大的放右邊，然後對左右子陣列遞迴。平均 O(N log N)。

void quickSort(int arr[], int lo, int hi) {   if (lo >= hi) return;   int pivot = partition(arr, lo, hi);   quickSort(arr, lo, pivot - 1);   quickSort(arr, pivot + 1, hi); }

🔀 5. 合併排序 (Merge Sort)

將陣列不斷切半直到長度為1，接著兩兩合併(Merge)成排序好的大陣列。需要暫存空間，時間 O(N log N)。

void mergeSort(int arr[], int lo, int hi) {   if (lo >= hi) return;   int mid = (lo + hi) / 2;   mergeSort(arr, lo, mid);   mergeSort(arr, mid + 1, hi);   merge(arr, lo, mid, hi); // 寫入暫存區再寫回 }
