C++ while 迴圈互動式教學

與 for 迴圈不同，while 專門處理「不知道會跑幾次，只要條件成立就繼續跑」的情況。

❤️ 1. 基礎條件迴圈 (HP 扣血)

先檢查條件，如果成立才執行迴圈內容。執行完再回來檢查條件。

int hp = 3; while (hp > 0) {     hp--; // 變數更新     cout << "扣血，剩餘: " << hp << endl; } cout << "Game Over!";

💣 2. 致命錯誤：無窮迴圈 (Infinite Loop)

初學者最常犯的錯：忘記在迴圈內更新變數，導致條件永遠成立，程式當機。

int power = 3; while (power > 0) {     cout << "攻擊！";     // 忘記寫 power--; }
Watch Box
變數 power = 3 (永遠不變)

🎲 3. do-while 迴圈 (擲骰子)

先執行一次內容，再來檢查條件。非常適合用在「要求輸入」或「隨機生成直到符合」的情境。

int num; do {     num = rand() % 6 + 1; // 產生 1~6 亂數     cout << "擲出: " << num << endl; } while (num != 6); cout << "出現 6 了，結束！";

🚦 4. while 中的 break 與 continue 陷阱

在 while 迴圈中使用 continue，若更新變數 (i++) 寫在後面，會被直接跳過導致無窮迴圈！
因此本範例將 i++ 放在最前面來確保安全。

int i = 0; while (i < 5) {     i++; // 💡寫在前面避免 continue 陷阱     if (i == 3) {         /* 請選擇操作 */     }     cout << i << " "; }
