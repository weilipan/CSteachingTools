🔢 1. 基礎計次 (Hello Loop)

for 迴圈最經典的用法就是「決定跑幾圈」。請觀察執行順序的顏色變化。

// 1.初始化 ; 2.條件判斷 ; 4.步進更新 for (int i = 1; i <= 3; i++) {     // 3. 迴圈內容     cout << "第 " << i << " 圈" << endl; }

⏱️ 2. 倒數與變速 (跳躍的變數)

迴圈不一定要從 0 開始，也不一定要每次 +1。你可以改變步進值來實現倒數或跳躍。

int step = 3; for (int i = 10; i > 0; i -= step) {     cout << i << " "; } cout << "發射！";

💰 3. 累加器應用 (經典加總)

在迴圈外部宣告變數，利用迴圈不斷更新它的值。觀察 sum 是如何膨脹的。

int sum = 0; for (int i = 1; i <= 5; i++) {     sum += i; } cout << "總和：" << sum;

🚦 4. 流程控制：break vs continue

當條件觸發時，continue 會跳過該回合剩下的程式碼並進入下一圈；break 則是直接砸毀整個迴圈。

for (int i = 1; i <= 5; i++) {     if (i == 3) {         /* 請選擇操作 */     }     cout << i << " "; }
