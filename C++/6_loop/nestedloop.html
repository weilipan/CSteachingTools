C++ 巢狀迴圈互動式教學

體驗二維邏輯：外層動一步，內層跑一圈。注意觀察藍色（外層）與黃色（內層）的交替節奏。

⚙️ 1. 時鐘齒輪機制 (外層與內層的關係)

想像外層是「小時」，內層是「分鐘」。分鐘必須跑完一整圈，小時才會進位。

// 外層迴圈 (小時) for (int h = 1; h <= 3; h++) {     // 內層迴圈 (分鐘)     for (int m = 1; m <= 4; m++) {         cout << h << "點 " << m << "分\n";     } }

🖨️ 2. 2D 空間建構 (矩形星星印表機)

外層控制「有幾行(Rows)」，內層控制「每行印幾顆星星(Cols)」。特別注意 換行 endl 的位置在內層結束後！

for (int i = 1; i <= rows; i++) {     for (int j = 1; j <= cols; j++) {         cout << "* ";     }     // 內層結束後，換下一行     cout << endl; }

📐 3. 變動邊界 (直角三角形)

內層迴圈不一定要跑固定的次數。如果把內層條件設為 j <= i，每行的星星數量就會隨行數增加。

for (int i = 1; i <= 4; i++) {     // 條件動態依賴外層變數 i     for (int j = 1; j <= i; j++) {         cout << "* ";     }     cout << endl; }
內層判斷條件
j <= i

✖️ 4. 數值連動 (乘法表)

外層變數與內層變數可以組合做運算，這是處理棋盤、網格數據最常見的技巧。

for (int i = 2; i <= 3; i++) {     for (int j = 1; j <= 4; j++) {         cout << i << " x " << j << " = " << (i*j) << endl;     }     cout << "------\n"; }
