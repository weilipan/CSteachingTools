📚 運作原理解析

預設模式 (Default)

當沒有設定 fixed 或 scientific 時，setprecision(n) 設定的是最大有效位數 (Significant Digits)，也就是「從第一個非零數字開始算起的總位數」。

  • 如果整數部分的位數超過 n，可能會自動切換成科學記號。
  • 預設會移除末尾無意義的 0，除非開啟了 std::showpoint。

std::fixed 模式

使用 std::fixed 後，setprecision(n) 的意義轉變為小數點後的位數。

  • 無論數值大小，都會強制以一般小數點形式顯示。
  • 若小數位數不足，會自動補 0 (此時 showpoint 無實質影響)。

std::scientific 模式

使用 std::scientific 後，setprecision(n) 設定的是科學記號中小數點後的位數。

  • 數值總是顯示為科學記號形式 (例如：1.23e+02)。
  • 小數點後必定保留 n 位，不足補 0。
