💡 電腦其實只有一排燈泡

你寫的 int、char，在電腦眼裡全都是一排小燈泡：亮 = 1、暗 = 0。今天我們只玩 8 顆，剛好是一個 char 的大小。

每顆燈泡都有自己的「面額」，從右邊開始是 1、2、4、8……每往左一格就翻一倍。把亮著的面額加起來，就是這排燈泡代表的數字。點點看吧！

unsigned char
🤔 為什麼要寫 (int)r？ 因為 cout 看到 char 會把它當成「文字」，印出奇怪的符號。先轉成 int，它才會乖乖印出數字。
📦 為什麼要存回 r？ C++ 做運算時會偷偷把 8 顆燈泡換成 32 顆的大盒子（int）。把結果存回 char，多出來的燈泡才會被切掉，跟上面的畫面一模一樣。

🔍 實戰一：奇數還是偶數？只看最後一顆燈泡！

除了最右邊那顆（面額 1），其他燈泡的面額都是 2、4、8……全是偶數。不管它們怎麼亮，加起來都是偶數。所以一個數字是奇是偶，只由最後一顆燈泡決定！

x & 1 就是派出 7 個守衛 🛡️ 把左邊 7 顆燈泡全擋住，只留下最後一顆來檢查。

if (x & 1) {// 最後一顆燈泡亮著 cout << "奇數"; } else { cout << "偶數"; }
🎯 冷知識：在 C++ 裡 -3 % 2 的答案是 -1，所以寫 if (x % 2 == 1) 會把負奇數誤判成偶數！x & 1 只看燈泡，正數負數都不會出錯。切到 Signed 輸入 -3 試試看。

🕳️ 實戰二：往左滑變兩倍，往右滑砍一半

每顆燈泡往左滑一格，面額就翻倍，所以 x << 1 就是 × 2。反過來往右滑一格，面額砍半，x >> 1 就是 ÷ 2。

但是！如果 x 是奇數，最右邊那顆「面額 1」的燈泡往右滑就沒地方站了，它會掉進黑洞永遠消失。那顆 1 就是被丟掉的「餘數」，所以整數除法才會無條件捨去。
