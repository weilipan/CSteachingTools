C++ 一維陣列 (1D Arrays) 互動式教學講義

一維陣列是記憶體中一塊連續的空間，用來儲存相同資料型態的元素。

1. 傳統索引迴圈 (Traditional For Loop)

利用計數器 i 作為索引值，精確控制存取的位置。

int arr[5] = {10, 20, 30, 40, 50};
for (int i = 0; i < 5; i++) {
    cout << arr[i] << " ";
}

2. 範圍基礎迴圈 (Range-based For Loop) 與累加應用

自動走訪陣列中的每一個元素，無需手動控制索引。

int arr[5] = {10, 20, 30, 40, 50};
int sum = 0;
for (int val : arr) {
    sum += val;
}
cout << "總和為: " << sum;

3. 進階應用：尋找最大值 (Advanced Applications)

利用遍歷技巧進行陣列資料處理，尋找陣列中的最大值。

int arr[5] = {15, 42, 8, 99, 23};
int max_val = arr[0];
for (int val : arr) {
    if (val > max_val) {
        max_val = val;
    }
}
cout << "最大值為: " << max_val;

4. 常見錯誤與除錯：陣列越界 (Out-of-bounds)

陣列大小為 5 時，最大的有效索引為 4。存取不屬於陣列的記憶體，將造成不可預期的錯誤。

int arr[5] = {10, 20, 30, 40, 50};
// 存取合法邊界 (索引 4)
cout << arr[4] << "\n";
// 越界存取 (存取不存在的索引 5)
cout << arr[5] << "\n";

5. 常見錯誤與除錯：未初始化 (Uninitialized)

宣告陣列若無賦值，裡面會充滿記憶體殘留的「垃圾值」(Garbage values)。

int arr[5]; // 未初始化
for(int i = 0; i < 5; i++) {
    cout << arr[i] << " ";
}
