⚖️ 2. 關係運算子 (Relational Operators)

==, !=, >, <, >=, <=  |  即時比較與常見錯誤說明

⚠️ 初學者常犯錯誤
==
if (a == b)
比較運算子：詢問「a 是否等於 b？」
運算結果是 bool 型態（true 或 false）。
=
a = b;
賦值運算子：把 b 的值「存進」a 裡面。
這不是比較！常見 Bug 來源：誤打成 if (a = b)
⚠️ 浮點數比較陷阱
C++ 中比較浮點數（float/double）時，因為二進位精確度誤差，0.1 + 0.2 == 0.3 往往會是 false。請避免直接使用 == 比較浮點數，應改用誤差範圍（epsilon）來判斷！

⚡ 4. 短路求值 (Short-Circuit Evaluation)

&& 遇 false / || 遇 true 立即停止，後方算式將被跳過不執行

A && (x++)

A 的值
x 初始值 = 0
A && (x++)
x 目前值 = 0

B || (y++)

B 的值
y 初始值 = 0
B || (y++)
y 目前值 = 0
💡 C++ 實務應用：防止程式崩潰 (Segmentation Fault)
if (ptr != nullptr && ptr->value == 10) { ... }

利用 && 的短路特性，當 ptr 為空指標時，第一項判斷為 false，程式便會立即停止檢查，絕對不會執行第二項 ptr->value，從而完美避免了存取空指標引發的嚴重當機錯誤。
