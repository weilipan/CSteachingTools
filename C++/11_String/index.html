① 記憶體彈性：char array vs std::string

傳統 char str[5] 容量固定，塞入過多字元會導致**溢位 (Overflow)**；而 std::string 具備動態配置能力，會隨內容自動拉伸。

char str[5] = "Hi"; // 容量固定為 5 string s = "Hi"; // 動態容量 // 嘗試塞入 "Hello World" ...

② 直覺的字串串接 (+ / +=)

不同於 C 語言需要使用 `strcat`，`std::string` 允許直接使用 `+` 號將字串像火車車廂一樣串接起來。

string s1 = "C++"; string s2 = " is "; string s3 = "Fun!"; string result = s1 + s2 + s3;

③ 輸入的陷阱：cin vs getline

cin >> s 遇到空白(Space/Tab)或換行就會停止讀取；若要讀取包含空白的整行文字，必須使用 getline(cin, s)。

string s; cin >> s; // 遇到空白就停 getline(cin, s); // 讀到換行才停

④ 安全存取：s[i] vs s.at(i)

存取字串元素時，s[i] 不會檢查邊界，越界會產生未定義行為(讀垃圾值)；s.at(i) 越界時會拋出 out_of_range 例外，較為安全。

string s = "C++"; // size: 3 char c1 = s[5]; // 越界：不會報錯，危險！ char c2 = s.at(5); // 越界：拋出異常，安全！

⑤ 字串搜尋 (s.find)

使用 s.find("目標") 來搜尋子字串。若找到，回傳起始索引；若找不到，回傳一個特殊常數 string::npos。

string s = "Programming"; size_t pos = s.find("gram"); if (pos != string::npos) {   cout << "Found at: " << pos; } else {   cout << "Not found"; }
