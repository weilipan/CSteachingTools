🔬 1. 字元與 ASCII 轉換 (X-Ray)

在 C++ 中，字元 (char) 在記憶體底層實際上是儲存為一個 0~127 的整數。這個對應關係稱為 ASCII 碼。

'0' – '9' → 48 – 57
'A' – 'Z' → 65 – 90
'a' – 'z' → 97 – 122
字元 →
65
整數 →
'A'
✅ 'A' 是大寫字母
➕ 2. 字元的數學運算

因為字元本質是整數，所以可以直接進行加減法。這在處理密碼學（如凱薩密碼）或大小寫轉換時非常實用。

char c = 'A'; char result = c + 3; // 'A'(65) + 3 = 68 ('D')
'A' +3 = 'D'
偏移量 +3
步驟 1：'A' 的 ASCII 是 65
步驟 2：65 + 3 = 68
步驟 3：轉回字元 (char)68 = 'D'
🔄 3. 大小寫轉換的秘密

大小寫字母在 ASCII 表中相差恰好 32。加上 32 變小寫，減去 32 變大寫。C++ 提供了 <cctype> 函式庫來簡化此操作。

#include <cctype> char lower = tolower('A'); // +32 char upper = toupper('b'); // -32

⌨️ 5. 跳脫字元 (Escape Sequences)

⚠️ 6. 初學者大坑：單引號 vs 雙引號

在 C++ 中，單引號 'A' 代表單一字元 (char)，雙引號 "A" 代表字串 (const char array)，字串會在結尾自動補上一個隱藏的 \0 (Null 字元)。型別完全不同！

char c = "A"; // ❌ 編譯錯誤！型別不符
char c = 'A';
char s[] = "A";
