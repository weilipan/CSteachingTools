⚡ C++ 前綴和 (Prefix Sum) 教學

用 O(N) 預處理換取 O(1) 區間查詢的魔法。對比 0-based 與 1-based 實作差異！

🏗️ 1. 建構前綴和陣列 (0-based)

int arr[5] = {3, 1, 4, 2, 5}; int prefix[5]; prefix[0] = arr[0]; for(int i = 1; i < 5; i++) {     prefix[i] = prefix[i-1] + arr[i]; }

💡 核心概念：prefix[i] 儲存了從 arr[0] 加到 arr[i] 的總和。

🏆 4. 完美解法：1-based Indexing (推薦)
