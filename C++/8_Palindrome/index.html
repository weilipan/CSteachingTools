🔄 C++ 雙指標與前綴和

🔍 1. 迴文判斷：雙指標對撞 (Two Pointers)

使用 L 與 R 指標從頭尾同時往中間檢查。若字元相同則繼續，直到相遇。

int L = 0, R = s.length() - 1; while (L < R) {   if (s[L] != s[R]) return false;   L++; R--; }

🧱 2. 建立前綴和陣列 (0-based Indexing)

陣列從 0 開始。prefix[i] 記錄從 index 0 到 i 的總和。注意 i=0 需要獨立處理！

prefix[0] = arr[0]; // 0-based 第一格獨立處理 for (int i = 1; i < N; i++) {   prefix[i] = prefix[i-1] + arr[i]; }

✂️ 3. 區間和查詢 (Range Sum Query)

計算 L 到 R 的總和，公式為 prefix[R] - prefix[L-1]。若 L=0，需特別防呆！

if (L == 0) {   sum = prefix[R]; } else {   sum = prefix[R] - prefix[L-1]; }
