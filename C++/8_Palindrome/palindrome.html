C++ 教學：一維陣列迴文 (1D Array Palindrome)

本講義旨在帶領學生由淺入深，從基本概念到實際撰寫雙指標（Two Pointers）演算法，學習如何在 C++ 中判斷一維陣列是否為迴文，並避免常見的陷阱與錯誤。

Stage 2: 基礎實作與範例 (Basic Implementation)

這是一種高效的演算法思維。我們不需要反轉整個陣列，只需設定左指標（left）與右指標（right）。以下程式碼示範如何使用 while 迴圈與雙指標來判斷整數陣列：

#include <iostream>
using namespace std;

int main() {
    int arr[] = {1, 2, 3, 2, 1};
    int n = sizeof(arr) / sizeof(arr[0]);
    
    int left = 0;
    int right = n - 1;
    bool isPalindrome = true;

    while (left < right) {
        if (arr[left] != arr[right]) {
            isPalindrome = false;
            break;
        }
        left++;
        right--;
    }

    if (isPalindrome) {
        cout << "這是一個迴文陣列！" << endl;
    } else {
        cout << "這不是一個迴文陣列。" << endl;
    }
    return 0;
}

Stage 3: 進階應用 - 延伸至字元陣列與字串

同樣的雙指標邏輯可以直接應用於 std::string。在進階應用中，我們將邏輯封裝為函式，並加入 tolower() 忽略大小寫，以及使用 isalnum() 跳過空白與標點符號：

#include <iostream>
#include <string>
#include <cctype>
using namespace std;

bool isStringPalindrome(string s) {
    int left = 0;
    int right = s.length() - 1;
    while (left < right) {
        if (!isalnum(s[left])) { 
            left++; continue; 
        }
        if (!isalnum(s[right])) { 
            right--; continue; 
        }
        if (tolower(s[left]) != tolower(s[right])) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

int main() {
    string text = "A man, a plan, a canal: Panama";
    if (isStringPalindrome(text)) {
        cout << "是迴文字串" << endl;
    } else {
        cout << "不是迴文字串" << endl;
    }
    return 0;
}
