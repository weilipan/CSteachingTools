🌟 2. 尋找最長迴文：中心擴展法 (Expand Around Center)

int L = center, R = center; while (L >= 0 && R < N && arr[L] == arr[R]) {   L--; R++; } int length = (R - 1) - (L + 1) + 1;

💡 指定一個「中心點」，雙指標向外擴展比對。當超出邊界或左右數值不相同時停止，計算擴展出的最大長度。

📊 3. 重排為迴文：頻率陣列 (Frequency Array)

for (int x : arr) freq[x]++; int oddCount = 0; for (int f : freq) {   if (f % 2 != 0) oddCount++; } if (oddCount > 1) return false; return true;

💡 若要把陣列元素重新排列成迴文，最多只允許「一個」數字出現奇數次（放正中央）。我們用頻率陣列統計次數。
