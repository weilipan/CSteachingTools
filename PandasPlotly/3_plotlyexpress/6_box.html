第六章：Plotly Express 箱型圖 (px.box) 與離群值

1. 準備對照資料 (顧客停留時間)

箱型圖最常用來尋找極端值與觀察資料集中趨勢。這裡我們收集了「台北」與「台中」分店在「平日/假日」的顧客座位停留時間。

import pandas as pd
import plotly.express as px

# 模擬包含正常值與極端值(如坐了一整天的客人)的資料
data = {
    '分店': ['台北']*10 + ['台中']*10,
    '平假日': ['平日']*5 + ['假日']*5 + ['平日']*5 + ['假日']*5,
    '停留時間 (分鐘)': [
        30, 45, 55, 65, 180,  # 台北平日 (180為離群值)
        40, 60, 80, 100, 240, # 台北假日 (240為離群值)
        20, 35, 45, 55, 90,   # 台中平日
        30, 50, 65, 80, 150   # 台中假日 (150為離群值)
    ]
}
df = pd.DataFrame(data)

📝 本章重點參數解析

  • x 與 y：通常 x 放入類別欄位（如分店），y 放入要觀察的數值欄位（如停留時間）。
  • points：箱型圖預設只會幫你把不合群的「離群值 (`'outliers'`)」畫成點。若設為 'all'，Plotly 會在箱子旁邊加上散佈圖（Jitter），讓你看清楚真實的資料密集度！
  • color：非常強大！除了 X 軸外，還可以再疊加一層分類。例如依據「平假日」分色，Plotly 會自動把平日與假日的箱子並排顯示，方便進行交叉比對。
  • notched：設為 True 時箱子會出現凹槽，這代表統計上的「中位數 95% 信賴區間」。這是一個讓圖表瞬間變得很「學術專業」的秘密武器！
