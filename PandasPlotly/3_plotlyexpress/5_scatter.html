第五章：Plotly Express 散佈圖 (px.scatter) 與趨勢線

1. 準備對照資料 (廣告費與營收)

散佈圖是用來觀察「兩個連續數值之間關聯性」的最佳圖表。加上趨勢線，更能秒懂資料的走向。這裡我們準備了一份「廣告費」與對應「營收」的數據。

import pandas as pd
import plotly.express as px

data = {
    '廣告費 (千元)': [10, 15, 22, 25, 30, 35, 42, 48, 55, 60, 68, 70],
    '營收 (萬元)': [15, 10, 30, 20, 25, 45, 50, 40, 65, 55, 80, 60],
    '地區': ['北區', '南區', '北區', '南區', '南區', '北區', '北區', '南區', '北區', '南區', '北區', '南區']
}
df = pd.DataFrame(data)

📝 本章重點參數解析

  • x 與 y：放入要觀察相關性的兩個連續數值欄位。
  • trendline：設定為 'ols' (Ordinary Least Squares) 時，Plotly 會自動透過 statsmodels 幫你計算並畫出線性迴歸趨勢線。
  • trendline_scope：當你有使用 color 將資料分組時，預設會幫每一個群體各畫一條趨勢線 ('trace')。若改為 'overall'，則無視分組，直接對所有資料點計算一條整體的趨勢線。
