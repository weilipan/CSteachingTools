第七章：Plotly Express 熱力圖 (px.density_heatmap)

1. 準備對照資料 (一週客流量紀錄)

熱力圖是尋找「熱區」的神器，非常適合觀察兩個類別變數的交叉分佈。我們準備了一份咖啡廳一週內不同「時段」與「星期」的客流量紀錄。

import pandas as pd
import plotly.express as px

# 模擬包含多筆「星期」與「時段」的原始紀錄 (此處為示意，實務上可能有上千筆)
data = {
    '星期': ['星期一', '星期一', '星期二', '星期六', '星期日', '星期日'],
    '時段': ['早上', '中午', '早上', '下午', '下午', '晚上'],
    '客流量': [25, 60, 30, 125, 120, 75]
}
df = pd.DataFrame(data)

📝 本章重點參數解析

  • x 與 y：分別放入兩個類別變數，Plotly 會自動幫你畫出一個網格（例如 X 軸是時段，Y 軸是星期）。
  • z：指定要被計算的數值欄位（如客流量、營業額）。如果不指定 z，熱力圖預設只會單純計算該格子的「資料筆數 (Count)」。
  • histfunc：決定 z 欄位的計算方式。最常用的是 'sum' (總和) 與 'avg' (平均值)。
  • color_continuous_scale：熱力圖的靈魂！選擇適合的漸層色票，能幫助閱讀者快速聚焦。深色或亮色通常代表數值較大。
  • text_auto：設為 True 時，格子裡面會直接印出數字，讓熱力圖兼具「視覺化」與「資料表」的雙重優點！
