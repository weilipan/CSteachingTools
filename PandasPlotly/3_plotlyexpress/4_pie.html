1. 準備對照資料 (各類飲品銷量與利潤)

圓餅圖最適合用來分析「各類別在整體中的佔比」。我們準備了五種熱門飲品的「銷量」以及隱藏的「利潤」資料來進行視覺化。

import pandas as pd
import plotly.express as px

data = {
    '飲品': ['美式咖啡', '拿鐵', '卡布奇諾', '焦糖瑪奇朵', '抹茶拿鐵'],
    '銷量 (杯)': [350, 420, 150, 180, 200],
    '利潤 (元)': [10500, 16800, 6000, 9000, 12000]
}
df = pd.DataFrame(data)

📝 本章重點參數解析

  • names：圓餅圖的「類別標籤」，也就是每塊餅代表的名稱（如本例的「飲品」）。
  • values：圓餅圖的「數值大小」，也就是決定每塊餅角度與面積的依據（如本例的「銷量」）。
  • hole：給定 0 到 1 之間的浮點數（例如 0.4），就能將圓餅圖中心挖空，瞬間變成現代感十足的「甜甜圈圖 (Donut Chart)」。
  • color_discrete_sequence：圓餅圖非常吃重配色。你可以傳入 Plotly 內建的色票（如 px.colors.qualitative.Pastel），或是自訂十六進位顏色列表來符合企業識別色。
  • hover_data：和前面的圖表一樣，你可以把版面放不下的詳細資訊（如「利潤」）藏在滑鼠懸浮提示中。
