第八章：Plotly Express 地理散佈圖 (px.scatter_geo)

1. 準備對照資料 (全球咖啡豆採購分佈)

要將資料畫在地圖上，最常見的做法是準備國家的 ISO Alpha-3 代碼 (三個英文字母) 或是經緯度。我們來看看咖啡廳從全球各地採購咖啡豆的分佈狀況！

import pandas as pd
import plotly.express as px

data = {
    '國家': ['巴西', '哥倫比亞', '衣索比亞', '越南', '印尼', '台灣', '義大利'],
    'ISO代碼': ['BRA', 'COL', 'ETH', 'VNM', 'IDN', 'TWN', 'ITA'],
    '洲別': ['美洲', '美洲', '非洲', '亞洲', '亞洲', '亞洲', '歐洲'],
    '採購量 (噸)': [850, 600, 500, 700, 300, 50, 120]
}
df = pd.DataFrame(data)

📝 本章重點參數解析

  • locations：告訴 Plotly 你的地理位置資料在哪個欄位。如果是國家，通常傳入 ISO Alpha-3 代碼（例如台灣是 TWN、日本是 JPN）。
  • projection：地圖投影法是 scatter_geo 的精華！
    • natural earth：視覺比例較為真實的平面展開圖。
    • orthographic：一秒變身可拖曳旋轉的 3D 地球儀，簡報效果極佳！
    • mercator：傳統的地圖投影，高緯度國家看起來會特別大（如格陵蘭）。
  • color 與 size：和一般的散佈圖一樣，你可以把地理散佈圖加上 size，瞬間升級成直觀的「氣泡地圖 (Bubble Map)」。
  • hover_name：當滑鼠游標移到點上時，作為大標題顯示的欄位（實務上通常會放國家的中文名稱，而不是難懂的 ISO 代碼）。
