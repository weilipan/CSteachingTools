1. 準備對照資料 (建立 DataFrame)

我們先建立一組簡單的「第一季咖啡銷量」資料表，並包含隱藏的「促銷活動」欄位，用以展現互動式圖表的魅力。

import pandas as pd
import plotly.express as px

data = {

📝 本章重點參數解析

  • color：依據設定的欄位將資料分組，畫出多條不同顏色的折線。
  • markers：設為 True 開啟資料點標記，折線轉折處會出現圓點，讓數據位置更明確。
  • line_dash：依據欄位自動分配線條樣式（實線、虛線等），非常適合用在可能需要黑白列印的報告中。
  • hover_data：Plotly 核心亮點！滑鼠停留在資料點上時，能額外顯示 DataFrame 內的隱藏資訊（如本例的促銷活動）。
  • labels：傳入字典 (Dictionary)，用來替換圖表上顯示的欄位名稱，讓 X/Y 軸說明更正式。
