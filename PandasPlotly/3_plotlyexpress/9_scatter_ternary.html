第九章：Plotly Express 三元散佈圖 (px.scatter_ternary) 與時間軸

1. 準備對照資料 (風味偏好演進)

三元圖 (Ternary Plot) 非常適合用來展示「三個變數加總為 100%」的資料組成。我們來觀察 2024~2026 年，三家分店顧客對咖啡豆「酸度、甜度、苦味」偏好的演進趨勢！

import pandas as pd
import plotly.express as px

# 準備包含三個組成變數 (加總為 100%) 以及時間維度 (年份) 的資料
data = {
    '年份': [2024, 2024, 2024, 2025, 2025, 2025, 2026, 2026, 2026],
    '分店': ['台北', '台中', '高雄', '台北', '台中', '高雄', '台北', '台中', '高雄'],
    '酸度 (%)': [30, 50, 20, 40, 40, 30, 50, 30, 40],
    '甜度 (%)': [40, 30, 20, 40, 40, 30, 30, 50, 40],
    '苦味 (%)': [30, 20, 60, 20, 20, 40, 20, 20, 20],
    '客流量':   [200, 150, 180, 250, 180, 220, 300, 200, 250]
}
df = pd.DataFrame(data)

📝 本章重點參數解析

  • a, b, c：三元圖專屬的坐標軸參數。放入加總會等於 100 (或 1) 的三個欄位，Plotly 會自動把資料投射到正三角形內部的相對位置。
  • animation_frame：🔥 動畫神器！ 指定一個代表時間序列的欄位（如年份、月份），圖表下方就會自動生成「播放鍵」與「滑桿」，讓資料點在地圖或座標系中隨著時間動起來。
  • animation_group：*(進階)* 當點有顏色分組，又開啟了動畫時，Plotly 需要追蹤「同一個物件」在不同影格的移動軌跡。這時可以設定 animation_group='分店' 來確保過場動畫平滑自然。
  • size：結合三元圖與氣泡圖，讓我們能同時觀察組成的比例 (A/B/C軸)、類別 (顏色)、以及總量 (氣泡大小)，是一張資訊密度極高的圖表！
